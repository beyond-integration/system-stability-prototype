# Changelog

## 0.1.0 - 2026-11-08

### Added
- Reproducible scientific prototype structure for compact exoplanet screening.
- Data validation pipeline for processed system tables.
- Hill, AMD, and resonance diagnostics.
- Screening decision logic with explicit abstention and follow-up states.
- Finite-horizon REBOUND numerical follow-up for selected systems.
- Output tables, figures, and logs for auditability.
- Release-oriented documentation, licensing, and citation metadata.

### Changed
- Finalized the repository to a portfolio-ready, honest scientific prototype rather than a broader research claim.
- Clarified that not all processed systems have saved REBOUND simulations.
- Tightened README and report language to avoid overclaiming long-term stability or resonance proof.

### Known limitations
- This is not a validated long-term stability model.
- Finite-horizon simulations do not establish billion-year stability.
- Resonance proximity is not resonance proof.
- The project is a reproducible prototype, not a publication-grade dynamical model.
